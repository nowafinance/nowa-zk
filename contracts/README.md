# Smart Contracts

Solidity contracts for ZK-Sequencer - batch verification and state management.

## Contracts

- **`BatchRegistry.sol`** - Registers batches, verifies ZK proofs
- **`StateManager.sol`** - Tracks state roots, validates updates  
- **`RollupVerifier.sol`** - ZK proof verifier (generated by prover)
- **`IVerifier.sol`** - Verifier interface
- **`MockVerifier.sol`** - Test verifier

## Quick Start

```bash
# Install dependencies
forge install

# Build
forge build

# Test
forge test

# Deploy locally
forge script script/Deploy.s.sol --rpc-url http://localhost:8545 --broadcast
```

## Testing

```bash
# Run all tests
forge test

# With verbosity
forge test -vvv

# Specific test
forge test --match-test testRevert_RegisterBatch_InvalidProof

# Coverage
forge coverage

# Gas snapshot
forge snapshot
```

## Deployment

### Local (Anvil)

```bash
# Terminal 1: Start Anvil
anvil

# Terminal 2: Deploy
forge script script/Deploy.s.sol --rpc-url http://localhost:8545 --broadcast
```

### Testnet/Mainnet

```bash
forge script script/Deploy.s.sol \
  --rpc-url $RPC_URL \
  --private-key $PRIVATE_KEY \
  --broadcast \
  --verify \
  --etherscan-api-key $ETHERSCAN_API_KEY
```

## Generated Contracts

The prover generates `RollupVerifier.sol`:

```bash
cd ../prover
./prover-bin setup
# Outputs to: contracts/src/generated/RollupVerifier.sol
```

Then rebuild contracts:

```bash
cd ../contracts
forge build
```

## Key Features

**BatchRegistry:**
- Two-phase commit (verify → finalize)
- Challenge period (7 days default)
- Sequential finalization
- Pause mechanism

**StateManager:**
- Sequential state root updates
- State root validation
- Batch tracking

**RollupVerifier:**
- Groth16 proof verification
- Auto-generated from circuit
- Gas-optimized
