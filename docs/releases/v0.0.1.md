# Release Notes: v0.0.1

## Title
**v0.0.1 - Initial Release: Nowa-ZK Sequencer**

## Description
We are proud to announce the **first official alpha release** of the **Nowa-ZK Sequencer**. This release establishes the core infrastructure for the Nowa-ZK Layer 1 network, delivering a high-performance, ZK-enabled transaction sequencing engine.

This initial version provides a complete end-to-end flow from transaction submission to ZK proof verification on-chain.

### 🚀 Key Features

*   **Core Sequencer Engine**:
    *   **Transaction Batching**: Efficiently groups user transactions into deterministic batches.
    *   **State Management**: Implements Sparse Merkle Trees (SMT) for secure and verifiable state transitions.
    *   **Reorg Protection**: Built-in mechanisms to handle chain reorganizations gracefully.

*   **Zero-Knowledge Proving**:
    *   **Gnark Integration**: Utilizes the `gnark` framework for generating Groth16 validity proofs.
    *   **Circuits**: Includes core circuits for state transitions and MiMC hashing.
    *   **Verifier**: Automated generation of Solidity verifier contracts.

*   **Smart Contracts**:
    *   **BatchRegistry**: On-chain storage and ordering of transaction batches.
    *   **StateManager**: Manages the global state root and validates state transitions via ZK proofs.

*   **Developer Experience**:
    *   **Local Devnet**: Full local stack setup via `make anvil` and `make deploy`.
    *   **Docker Support**: Containerized environment for reproducible builds.
    *   **Traffic Generator**: Built-in tool to simulate network load for testing.

### 📦 Installation / Usage

Clone the repository and build the binaries:

```bash
make setup
make build
```

To run a local development environment:

```bash
# Terminal 1: Start local chain
make anvil

# Terminal 2: Deploy contracts
make deploy

# Terminal 3: Start Sequencer
make run-sequencer

# Terminal 4: Start Prover
make run-prover
```
